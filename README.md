# weekly-idiom-web

"이번 주의 사자성어"를 브라우저에서 바로 보여주는 정적 페이지입니다.
[weekly-idiom-printer](https://github.com/goblacksun-crypto/weekly-idiom-printer)
(비공개 저장소, 집 프린터 자동 인쇄용)의 `index.html`만 공개용으로 분리했습니다.

민감한 정보(가정용 프린터 IP 등)는 포함되어 있지 않습니다.

GitHub Pages: 저장소 Settings → Pages → Source를 "Deploy from a branch" /
`main` / `/(root)`로 설정하면 아래 형태의 주소로 공개됩니다.

```
https://<GitHub 계정명>.github.io/weekly-idiom-web/
```
